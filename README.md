# Clovis Web Design — Bespoke Concept

> Hand-built, fast websites for Fresno and Central Valley businesses. Designed, written and engineered by one person in Clovis, CA. Bespoke concept by Adam Youssef.

## Tech Stack
- React 19 + TypeScript
- Vite 7 + Tailwind CSS v4

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
